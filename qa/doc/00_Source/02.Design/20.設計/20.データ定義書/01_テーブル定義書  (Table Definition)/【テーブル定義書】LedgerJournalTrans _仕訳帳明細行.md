<a id="q01"></a>
### Q01 テーブル物理名の末尾空白

**出典**：テーブル定義「テーブル名（物理）」。

**背景**：原資料の保存値は `LedgerJournalTrans␠`。`␠`は末尾の半角空白1文字（U+0020）を可視化した記号である。ファイル名でもTransの後に空白がある。空白を削除して正式名称を決めたわけではない。

**質問**：正式なテーブル物理名の扱いを選択してください。（単一選択）

| 選択肢 | 回答内容 |
| --- | --- |
| A | 末尾空白なしのLedgerJournalTransが正式で、表の末尾空白は不要。 |
| B | 原資料の末尾空白には意図がある（意図を補足）。 |
| C | その他（正式名称・対応方針を補足）。 |
| D | 未定・要調査。 |

### Q02 支払提案の列挙型名の空白
