# 可視範囲限定の変換

## 優先規則

`AGENTS.md` と利用者の最新指示を優先する。非表示のシート・行・列は本文、質問、網羅性の評価対象から除外する。`hidden` と `veryHidden` の両方を除外し、列範囲の指定やゼロ寸法にも対応する。

保存された表示状態を使う。画面外へスクロールしたセル、ウィンドウ固定や印刷範囲外という理由だけでは除外しない。フィルター条件を独自に再実行せず、保存されたhidden状態を使用する。outlineLevelやcollapsed属性だけで表示セルを落とさない。

## 実装

`src/visible_scope.py` は標準ライブラリでOOXMLから表示範囲を判定する。`xlsx_spec.py` と旧 `evaluate_markdown.py` は同じスコープを使い、隠された値・注釈・リンクを一時的な読み取りオブジェクトから除く。元のブックを保存し直さない。

可視セルの保存済み計算値は残す。非表示セルを空白扱いしてCOUNTAを再計算しない。保存済み値がなく非表示領域を参照する場合は未確定とする。

`drawing_content.py` は非表示のシートと図形・グループを除外する。図形が全体として非表示範囲に縮小される場合と、浮動表示・部分的な重なりがある場合を区別する。後者は警告を付け、目視で確認する。画像の意味理解、図形の接続先、条件付き書式の完全な画面再現を自動で保証する機能ではない。

凡例・履歴というシートは機械的に除外する。可視シートの中にある凡例・履歴の区画は、文書構造と表示を確認して除く。テンプレートの説明を業務要求と取り違えない。

## 検証

```bash
python -m unittest discover -s tests -p test_visible_scope.py -v
python -m unittest discover -s tests -p test_hidden_formula_guard.py -v
```

15件のスコープテストと4件の数式ガードテスト。これらは部品テストであり、実ワークブックの全体変換合格を意味しない。古いワークブック専用contractは表示範囲変更後に独立レビューし直す。出力に存在する単語だけで合格にしない。

## 保存先

`input/<相対パス>/<名前>.xlsx` に対して、`output`、`qa`、`report` のそれぞれで同じ相対パスとファイル名を使用し、拡張子を `.md` にする。UTF-8（BOMなし）、mainを直接操作する。

仕様をoutput、質問をqa、対象範囲・読み方・結果・制約をreportへ分離する。質問は単一選択または複数選択を明示し、その他・未定を用意して未回答で保存する。

完全な取得・目視確認・品質確認が終わらない場合は、部分変換または未完了と明記する。空の本文や取得していない内容を完成品として保存しない。
